# Intent: refresh the five Factory GitHub Pages sites

## Problem

The public sites show the suite as it was in the summer. Visitors, and anyone
sent a link from a post or a demo, see features, versions and architecture
that are months out of date, and in places wrong.

| Site | Source | Newest post | Homepage last changed | Shipped since 2026-08-10 |
| ---- | ------ | ----------- | --------------------- | ------------------------ |
| factory.freundcloud.com | Factory `main:/docs` (Jekyll) | 2026-08-10 | 2026-07-30 | 166 merged PRs (08-11 to 11-15); roadmap last updated 2026-10-24 |
| aifactory.freundcloud.com | AIFactory `docs/` (Docusaurus, built from `main` to `gh-pages`) | 2026-08-10 | 2026-06-18 (`src/pages/index.tsx`) | 35 releases, v3.6.74 → v3.10.16 |
| pfactory.freundcloud.com | PFactory `main:/docs` (Jekyll) | 2026-08-10 | 2026-09-03 | 26 releases, v0.6.17 → v0.6.42 |
| tfactory.freundcloud.com | TFactory `main:/docs` (Jekyll) | 2026-08-10 | 2026-08-05 | 24 releases, v0.9.26 → v0.9.49 |
| cfactory.freundcloud.com | CFactory `main:/docs` (Jekyll) | 2026-08-10 | 2026-07-26 | 116 merged PRs, of which 23 reached `main`; no GitHub releases |

Some `docs/` pages did change after August (Factory RFCs 0023–0025 and the
demo runbook, PFactory's review lenses, TFactory's capabilities guide,
CFactory's planning-board and card-sync guides). The updates were uneven. The
headline story (homepages, posts, roadmaps, version labels) stayed frozen,
and it now contradicts the newer pages.

Stale or wrong content found in review (Codex, agy, verified against origin):

- **Version labels:** every page footer shows `v0.6.16` (PFactory),
  `v0.9.3` (TFactory) and `v0.1.0-skeleton` (CFactory) from `_config.yml`
  `release_tag`. TFactory's homepage stat grid still shows the May
  `v0.1.0-mvp` numbers. PFactory's says 8 stages and 4 review gates.
- **AIFactory roadmap and concepts:** `/roadmap` says "open-core" (the site
  says MIT OR GPL-3.0) and lists shipped epics as upcoming. Concept pages
  frame features around v1.1/v1.2.
- **Architecture and guide pages contradict shipped behaviour:** Factory
  (dedup key, correlation key form, HMAC versus Ed25519 signing, port
  numbers, future-tense EU AI Act date), PFactory (8 versus 10 stages),
  TFactory (Java shown as unsupported, Docker-era runner, PARR spelled out
  wrongly on one page), CFactory (stalled-work pruning, Job-native "reverted",
  view count, PFactory port).
- **Suite links:** CFactory is linked to GitHub, not its site, from the
  Factory, AIFactory, PFactory and TFactory pages. PFactory still says "three
  factories".
- **Broken links and assets:** AIFactory has 404 GitHub links, `/docs/...`
  paths that do not exist, 4 missing blog images and a duplicate sidebar
  entry. Factory has an RFC link with the wrong path and `policies/` links
  that 404. PFactory has 3 links to renamed RFC files. TFactory's hero
  "See the demo" path leads to a CHANGELOG anchor that 404s.
- **RFCs are hard to find:** Factory has 27 RFC files up to RFC-0025, no
  `/rfc/` index and no nav entry.
- **Private details are published:** Factory compliance pages name the
  cluster hosts. A PFactory plan page publishes a tailnet URL.

## Proposed outcome

On all five sites:

- The homepage describes what the product does today: headline features,
  current status, working links. Stat grids hold true numbers or are removed.
- Footers no longer carry a hand-written version string that goes stale.
- One new post per site covers what shipped from 2026-08-10 to 2026-11-15.
  Every claim in it links to a release, PR or RFC.
- The roadmap or progress page (including AIFactory's `/roadmap`) says what
  shipped and what is next as of November 2026.
- The architecture and guide pages named above match shipped behaviour.
- Suite links point to the five `*.freundcloud.com` sites, and each site
  names all four products.
- The listed broken links and images are fixed or removed.
- factory.freundcloud.com has an RFC index with each RFC's status.
- No private host names or tailnet URLs appear on any published page.
- All five sites are live with the new content, checked in a browser.

## Affected users and systems

- Repositories: Factory, AIFactory, PFactory, TFactory, CFactory, `docs/`
  only.
- Readers of the five sites. Posts and demos that link to them.
- No services, clusters or hosts are touched. Each repo's `deploy.yml`
  ignores `docs/**`.

## Constraints

- Docs only: no code, workflow or runtime config changes outside `docs/`.
- AIFactory, PFactory, TFactory and CFactory take PRs on `dev`, and `main`
  is their release branch. Their sites deploy from `main`. Factory deploys
  straight from `main`.
- "Shipped" means in a release tag, or merged to `main`, by 2026-11-15.
  Work merged only to `dev` is described as in progress, never as shipped.
  An RFC's own status line decides whether it counts as shipped.
- Every claim holds up against a release note, a merged PR or an RFC
  status. This follows the 2026-08-10 "only claim it when you can prove it"
  post.
- Keep each site's layout, theme and URLs. No redesign.
- No customer names, private hosts, tailnet names or secrets in public pages.

## Decisions (approver pre-approved all gates on 2026-11-15)

1. **Scope:** everything in "Proposed outcome", across all five sites.
2. **Going live:** docs land on `dev` by PR, then reach `main` through a
   docs-only `sync/dev-to-main-<n>` PR (CFactory's precedent). No code
   promotion and no release just for docs.
3. **Screenshots:** reuse existing images. Image references that point
   nowhere are removed. No cluster access.
4. **MCP-AgentGateway:** left out; it is not part of the suite.

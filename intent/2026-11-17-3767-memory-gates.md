# Intent: RFC-0021 Phase 4, validation and trust gates

## Problem

Phase 3 records signals but nothing decides which ones become durable memory.
Without gates, an error seen once, an approach the session abandoned, or a
"lesson" the agent merely read on a web page would all be written, which is the
failure RFC-0021 section 3.2 describes.

## Proposed outcome

At session end, the scratchpad signals pass ordered gates before anything is
written to `gotchas.md`: validation (abandoned approaches dropped, except as
dead_end), frequency (must recur), novelty (exact repeat of an existing gotcha),
trust (signals observed after untrusted content do not count), then score and
cap. Each gate has a mutation check that fails when the gate is removed.
Duplicate rate and store growth are measured against the section 6.1 baseline.

## Affected users and systems

AIFactory, PFactory, TFactory `apps/backend/memory/` (new `gates.py`, call from
`save_session_insights`), the web-content hook that marks untrusted turns.
Blocked on Phase 3 (#3766). Vendored tree: all three or none.

## Constraints

- Deterministic, no LLM call added (survivors are written as fixed-form text).
- Caps from Phase 2 still bound writes. Graphiti not extended. Project-scoped.
- Known Phase 2 gap kept: Graphiti write path bypasses caps.

## Open questions

None open. Decisions (owner delegation 2026-11-17), each a deliberate
reduction of RFC section 3.2 that the RFC text will record:

- Scope of the gates: promotion of scratchpad signals into `gotchas.md`. The
  agent's explicit `record_gotcha` stays under the Phase 1 repeat gate and the
  Phase 2 cap; when it runs inside the untrusted window its entry carries an
  "unverified" source line instead of being blocked.
- Trust marker: a time window (10 minutes) opened when an external-content tool
  runs (AIFactory `web_fetch`, the PF/TF `WebFetch`/`WebSearch` hooks), never
  cleared by another session, so overlapping sessions can only cause
  under-promotion, never over-promotion.
- Novelty stays exact-repeat (what Phase 1 shipped); semantic similarity needs
  an embedder the pods do not have. Synthesis is a fixed-form sentence, no LLM
  call, so the LLM call count does not rise.
- Measures carried: duplicate rate and store growth against the section 6.1
  baseline; retrieved-memory tokens N/A (the gates change what is written, the
  Phase 5 ranking governs what is loaded) and stated as such in the PR.
- Original text kept below.

Original open question: the trust marker is a process-wide flag; it errs toward
under-promotion.

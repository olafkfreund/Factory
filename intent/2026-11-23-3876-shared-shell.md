# Intent: one shared layout so the five portals read as one product

## Problem

The portals look like five products. Owner (2026-11-23): "make the UI
shared design and make it look like one product, that is really important
for the users and the branding."

Measured on prod at 1559px:

| Portal | Above the content | Content starts at |
|---|---|---|
| CFactory | 56px top bar + 72px pipeline strip | 128px |
| TFactory | project tab row, page title, 240px pipeline rail panel | 374px |
| AIFactory | the same pattern as TFactory, plus a coloured project tab row | ~370px |

PFactory has the same pattern plus 1,109 lines of its own CSS (animated
rings, flying documents, stickers). RFactory has its own markup.

The shells are per-portal copies that have drifted:
- `Sidebar.tsx` differs by 44–69 lines between portals;
- `ProjectTabBar.tsx` by 31–54 lines;
- `App.tsx` by 318 lines.

Projects are switched in three different ways.

## Proposed outcome

Every portal renders the same hub-owned shell:
- the same top bar, compact like CFactory's;
- the same compact pipeline strip;
- the same sidebar;
- the same page header, plus the same empty, loading and error states;
- one project switcher (the breadcrumb).

Each portal supplies only its navigation items, its pipeline stages and
its pages. The shell is vendored byte-exact and drift-gated, so it cannot
diverge again. The owner sees one product with five accent colours.

## Affected users and systems

- Factory `shared/factory-ui`.
- The web UIs of AIFactory, PFactory, TFactory, CFactory and RFactory.

## Constraints

- **Shared styling** is plain CSS on the `--f-*` tokens (Factory#3875).
  CFactory and RFactory don't use Tailwind.
- **Every capability survives the move:** project switching, Add project,
  settings, Needs-you, search and the theme.
- **CLI and MCP parity is unchanged** (the plan's Phase D).
- **Adoption is one portal at a time,** TFactory first, with an owner
  side-by-side check before the rest.
- **Browser test** at 1280px and 390px after each portal.

## Open questions

None. The owner chose the CFactory top-bar model and one shared layout.

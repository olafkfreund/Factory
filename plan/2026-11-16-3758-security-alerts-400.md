# Plan: security-alerts no_field handling (#3758)

Decisions carried from the approved spec: a 400 whose body is OpenObserve's "Search field not
found: No field named action" (`code` 20004) becomes status `no_field`, n=None, rc 0 (accepted degraded detection, see spec), recorded in `job_health`; every other
400/5xx/transport error stays `error` (rc 1); 404 stays `no_source`; `not_configured` stays rc 0;
no body, value or `str(e)` is printed.

# Plan: validation and trust gates (RFC-0021 Phase 4)

Self-contained summary of the approved spec `spec/2026-11-17-3767-memory-gates.md`.
Depends on Phase 3 (plan 3766) being done first in the same branch.
Work happens on branch `feat/3765-memory-phases-3-5` in AIFactory, PFactory and
TFactory (base `dev`; one branch and one PR per repo carries all three issues,
steps run 3765, 3766, 3767) and `docs/389-memory-phases-3-5` in Factory (base
`main`, artifacts and RFC). All code paths are under `apps/backend/`; tests are
in the repo-root `tests/` (run pytest from the repo root: AIFactory
`apps/backend/.venv/bin/pytest`, PFactory/TFactory their own venv or
`python -m pytest`). Traps for every step: AIFactory's ruff and
`standards/ruff.toml` disagree on sorting "as" aliases in parenthesised imports
(use plain names); each repo keeps its own formatting (run its ruff); never
touch the live cluster; standard library only; Graphiti is not extended;
memory stays project-scoped, `dead_end` is never shared across projects; no
Aperant code (AGPL).

Decisions: `memory/trust.py`: `TRUST_WINDOW=600` seconds, `taint(now=None)`
stores `time.monotonic()`, `tainted(now=None)` true inside the window, never
cleared by a session end. `memory/hooks.py` adds async `taint_hook(input_data,
tool_use_id=None, context=None)` returning `{}` after `taint()`; registered as
`PreToolUse` `HookMatcher(matcher="WebFetch")` and `matcher="WebSearch"` in
`core/client.py` of all three repos; AIFactory `guarded_web_fetch` also calls
`taint()` on entry. The Phase 3 callers (failure hook, `record_dead_end` tool) pass
`untrusted=trust.tainted()`. `memory/gates.py`: signals are scratchpad entries
plus kind; `GATES` = [validation, frequency, novelty, trust, score_cap]
(ordered pure functions over lists). dead_end signals are removed before the pipeline
(recalled directly, never written to `gotchas.md`). validation: keep
`n - ab >= 1`. frequency: `n >= MIN_COUNT=2`. novelty: drop if the
STORED form of the text (rendered sentence through
`escape_headings`) equals the stripped body of an entry in `gotchas.md` (split with
`retention.split_gotchas`, marker suffix removed) or `promoted`. trust: keep `bad == 0`. score_cap: rank `(n, last)` desc, keep
`CAPS[session_type]`. Synthesis fixed form `Recurring <kind, underscores as
spaces> (seen N times): <text>`. Write: body through new
`retention.escape_headings` (the regex now inline in `record_gotcha`, moved to
a helper and reused), one append of `## [YYYY-MM-DD HH:MM]` entries, mark
`promoted`, `confirm()` the stored (escaped, stripped) bodies, the same
representation `gotchas_context` hashes. `promote(memory_dir, session_type=None, now=None)`
returns the written bodies, never raises, runs at the end of
`save_session_insights` for `spec_dir / "memory"` inside try/except.
`record_gotcha`: when `trust.tainted()` the body gets a trailing line
`_Source: unverified (external content read in this session)_` (constant
`UNVERIFIED`). The repeat gate stays on the plain body: when building `seen` from
the stored tail each segment has a trailing `UNVERIFIED` removed, and the
confirm of a repeat stamps both the plain body and plain + `UNVERIFIED`; a new
entry stamps the stored (marked) body.
Not in scope: semantic novelty, LLM synthesis, locking, Graphiti write path.

## Steps

1. AIFactory `memory/trust.py` (new), `memory/hooks.py` (add `taint_hook`),
   `core/client.py` (register), `agents/tools_pkg/tools/web.py`
   (`guarded_web_fetch` calls `taint()`), and pass `untrusted=trust.tainted()`
   in the Phase 3 callers. Check: `python -c "import core.client"`.
2. AIFactory `memory/gates.py` (new) and `memory/retention.py`
   (`escape_headings`). Check: step 4 tests.
3. AIFactory `memory/sessions.py` (call `promote` at the end of
   `save_session_insights`) and `agents/tools_pkg/tools/memory.py`
   (`record_gotcha` uses `escape_headings` and the unverified marker). Check:
   existing `tests/test_memory_novelty.py`, `tests/test_memory_retention.py`
   unchanged green.
4. AIFactory `tests/test_memory_gates.py` (new): each gate alone; ordered
   pipeline; trust window (inside, after, `now` injected); promote writes once
   and is idempotent; cap; heading escape for multiline text; `record_gotcha`
   marker when tainted and none when not; `save_session_insights` integration;
   hooks registered in `core/client.py` (source check) and `taint_hook`
   effect; measures test (20 simulated sessions: 3 recurring errors, 6 one-off,
   2 tainted repeats) printing items written, exact duplicate pairs and bytes
   without gates (every observation written) vs gated, asserting gated is
   strictly smaller and has 0 duplicates. Mutations, each red: remove each of
   validation, frequency, novelty, trust, score_cap from `GATES`; remove the
   `dead_end` exemption; remove the marker; remove `taint_hook` registration.
   Check: `pytest tests/test_memory_gates.py -q`.
5. PFactory: port steps 1-4. 6. TFactory: port steps 1-4. Per repo: ruff, touched
   tests, then `codex review --base origin/dev` (max 2 rounds), rebase on
   `origin/dev`, push, open the PR ("Refs olafkfreund/Factory#389", links the
   nine artifacts, measures table), wait for checks on the head SHA.
7. Factory `docs/rfc/0021-earned-memory-and-promotion-gates.md`: add
   "6.2 Phase 3-5 measures (2026-11-17)" with the measured numbers and a
   one-paragraph "Implementation notes" recording the reductions (exact-repeat
   novelty, fixed-form synthesis, time-window trust, PF/TF same-spec recall).
   Do not tick checkboxes (epic and RFC tick when the three PRs merge). Factory
   PR carries intent, spec, plan and RFC change.

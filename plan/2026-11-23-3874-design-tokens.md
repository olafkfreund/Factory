# Plan: hub design tokens and gates (#3874)

The spec's design is the contract: the token tables, the bridge mapping
and the gates. Branch `feat/3874-design-tokens`. Steps 1 and 5 go to agy;
steps 2, 3 and 4 go to Codex.

## Steps

1. `shared/factory-ui/tokens.css` and `shared/factory-ui/tailwind-theme.css`,
   exactly per the spec tables.
2. `scripts/check_token_contrast.py`, stdlib only, plus
   `tests/test_token_contrast.py` (including a weakened-token failure case);
   wire it into `.github/workflows/factory-ui-drift.yml`, or the workflow
   that runs `check_factory_ui_drift.py` in this repo.
   → verify: `python scripts/check_token_contrast.py && pytest tests/test_token_contrast.py -q`.
3. `scripts/check_factory_ui_drift.py`: CSS files, per-file destinations,
   the cfactory and rfactory token-only layouts, and the `*.css` unlisted
   guard. Update `tests/test_check_factory_ui_drift*.py`.
   → verify: `pytest tests -q -k factory_ui`.
4. `scripts/check_banned_constructs.py`: the small-text rule, plus tests.
   → verify: `pytest tests -q -k banned`.
5. `PortalSwitcher.tsx`: the Meet entry and `var(--f-*)` dots.
   `shared/factory-ui/README.md`: document tokens, the bridge, the gates
   and the vendoring subsets.

Traps:
- byte-exact vendoring means portals must not edit the copies;
- the Factory ratchet covers `scripts` and `tests` (Python);
- no Node build in this repo for the CSS.

## Tests

As each step lists, plus `pytest tests/ shared/factory-common/tests/ -q`.

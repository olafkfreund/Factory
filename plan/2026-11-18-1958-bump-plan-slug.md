# Plan: Plan-Slug trailer on the gitops bump (PFactory, TFactory, CFactory)

Approved decisions (spec): one script `scripts/plan_slug_trailers.sh [BASE]`
per repo, identical bytes. It examines `BASE..HEAD` if BASE resolves, else HEAD;
per commit takes all `Plan-Slug:` trailers via `git interpret-trailers --parse`;
keeps those matching `^[A-Za-z0-9._/#:-]{1,128}$`; dedups newest first; caps at
10; prints `Plan-Slug: <slug>` lines; always exits 0. Deploy bump step: checkout
`fetch-depth: 0`; in the retry loop read the old `newTag: sha-<short>` from the
gitops kustomization BEFORE `kustomize edit set image`; run the script with
`$GITHUB_WORKSPACE` as cwd; commit message = subject, blank line, trailers (no
blank line when none). AIFactory unchanged. Branches off origin/dev; PRs to dev.
Worktrees under the scratchpad `teams/plan-slug-bump/`.

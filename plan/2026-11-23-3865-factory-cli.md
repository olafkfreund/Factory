# Plan: `factory` CLI and MCP front door, release 1 (#3865)

Self-contained. Everything below restates the approved spec decisions;
the spec stays at `spec/2026-11-23-3865-factory-cli.md`.

## Decisions carried from the spec

- **Package:** `shared/factory-cli` (Python ≥ 3.11, `pyproject.toml`,
  entry point `factory`).
  - Deps: stdlib urllib, pyyaml, and `mcp` (pinned range, lazy import).
  - Vendors `factory_common` at build time.
  - `flake.nix` gains `packages.factory-cli` and `apps.factory`.
- **Keys:** looked up as `$<P>_MCP_KEY` → `~/.<p>/.mcp-key` →
  `$<P>_API_TOKEN_FILE` → `~/.<p>/.token`. CFactory uses
  `$CFACTORY_API_KEY` → `~/.cfactory/.mcp-key` → `~/.cfactory/.token`.
  - The owner's keys at `~/.<p>/.token` were verified live on 2026-11-23.
    They are user `acw_` keys that pass the scoped routes, and PFactory's
    has `plan:write`.
- **Default URLs:**
  - `https://pfactory.freundcloud.org.uk`
  - `https://aifactory.freundcloud.org.uk`
  - `https://tfactory.freundcloud.org.uk`
  - `https://cfactory-mcp.freundcloud.org.uk`. The main CFactory host
    redirects to SSO.
- **Routes:** PFactory, AIFactory and TFactory are called only through
  `/api/mcp-stdio/*`, because `/api/*` needs `api:full`. CFactory uses
  `/api/workitems/*` and `/health`.
- **Transport:**
  - https, or http only to loopback;
  - reject URL userinfo;
  - no redirects;
  - redact the loaded key value and secret patterns everywhere, MCP
    output included.
- **`submit`, client side:**
  - all three files committed, `status: approved`, working copy clean;
  - each file has an approval commit that is an ancestor of HEAD, flips
    `draft→approved`, and the blob is unchanged since;
  - SHA-1 repos only;
  - sequence: `ingest-approved` → `approve` → live `emit-contract`;
  - exit codes 0, 1 (4xx), 2 (local precondition), 3 (outcome unknown);
  - never repeats an emit POST.
- **`submit`, PFactory side:**
  - Mapper `plan/ingest/artifacts.py`: one child per `## Steps` item, in
    order, each depending on the previous step. All spec `## Verification`
    criteria go verbatim on the final child, with Tests and Rollback
    appended to it. `content_trust="untrusted_user_content"`.
  - Route `/api/mcp-stdio/plan/sessions/ingest-approved` (`plan:write`):
    - `extra=forbid`, with bounded fields;
    - server-side git blob framing check;
    - authorization before dedupe;
    - runs the non-authoring `process()` stages (classification,
      grounding, injection scan, review runner + `run_gates`,
      `annotate_plan`, `_save`) and sets `session.epic` from the mapper;
    - `source_artifacts` session field.
  - Artifact sessions are refused (409) by the edit, apply and reprocess
    routes.
  - Dedupe: the key is (tenant, org, project, provider, repo, base_ref,
    3 blob SHAs), claimed via the lease. An already-emitted session
    returns its stored `contract_result`.
  - Emit for artifact sessions:
    - `require_user_approval` is forced on;
    - a signing key is required;
    - `allow_fallback=False`;
    - repo and project are taken from the session;
    - the lease is held.
  - Contract fields:
    - `provenance.source_artifacts`, items carrying
      `attested_by: "client"`;
    - `provenance.human_approval`, with `user_id` from the authenticated
      key and `approver_display` resolved server-side.
- **`test`:**
  - `--project` is required;
  - TFactory adds `no_register` to the scoped ingest, so unknown and
    invisible projects get the identical 404;
  - criteria are rewritten as an `## Acceptance Criteria` section `AC1..n`;
  - run id: `<stem>-<short sha>-<utc stamp>`, limited to `[a-z0-9-]` and
    64 characters;
  - `pr_number` goes in the ingest body;
  - `planner_scheduled=false` comes with a reason.
- **`status`:**
  - `pf:` → PFactory session plus the AIFactory task;
  - `af:` → `/api/mcp-stdio/tasks/{id}`;
  - `tf:` → `/api/mcp-stdio/spec-tasks/{p}/{s}`;
  - a bare correlation key → CFactory work item, only when a CFactory key
    is set; otherwise exit 2;
  - every 404 is printed as "not found".
- **`mcp`:**
  - `factory mcp` serves `factory_submit` (dry-run by default),
    `factory_test`, `factory_status` and `factory_doctor`.
  - `mcp-config claude|codex|agy` prints a secret-free entry. The agy
    config path is `~/.gemini/config/mcp_config.json`.
  - `--write` merges only the `factory` entry and refuses an existing one
    without `--force`. JSON files are rewritten; Codex TOML is appended to.
    It keeps a 0600 `.bak` and replaces the file atomically.

## Steps

Repos: Factory `/mnt/code/Source-home/GitHub/Factory` (base `main`),
PFactory, TFactory and AIFactory clones (base `dev`). One branch and PR per
repo:
- Factory: `feat/3865-factory-cli` (this branch);
- products: `feat/3865-<short>`.

Each worktree lives under the session scratchpad.

1. **Factory: contract schema.**
   - Change:
     - `apis/task-contract.schema.json` `provenance` (`:19`): add optional
       `source_artifacts` (array of objects: `stage` enum
       intent|spec|plan, `path`, `blob_sha` /^[0-9a-f]{40}$/,
       `approve_commit_sha` same pattern, `approve_commit_author`
       maxLength 200, `attested_by` const "client") and `human_approval`
       (`user_id`, `approver_display`, `auth_kind`, `approved_at`
       date-time, `plan_hash`).
     - Keep `additionalProperties: true`.
     - Regenerate with `python scripts/gen_contracts.py`.
   - Verify by: `python scripts/gen_contracts.py --check` (or the repo's
     contract drift check in CI) and `pytest shared/factory-contracts`.
   - Traps: the generated Python and TS output must be committed together;
     never hand-edit generated files.

2. **PFactory: mapper.**
   - Change: new `apps/backend/plan/ingest/artifacts.py`, modelled on
     `plan/ingest/speckit.py` (`ingest_speckit`, `_epic_from_tasks`,
     `_section_lines`).
     - `ingest_artifacts(intent_md, spec_md, plan_md, slug) ->
       (NormalizedPlan, EpicPlan)` builds the result as in the decisions
       above.
     - Child kind uses speckit's mapping, defaulting to `implementation`;
       a step naming tests or CI becomes `testing`/`ci`.
     - Raises `ArtifactIngestError` when there are no steps.
   - Tests: `apps/backend/tests/plan/test_ingest_artifacts.py`, using
     fixtures copied from real Factory triples (this plan's own, plus
     `2026-11-19-3858-factory-ui-breadcrumb`).
   - Verify by: `pytest apps/backend/tests/plan/test_ingest_artifacts.py -q`,
     then the ratchet:
     `python scripts/ratchet_lint.py --base origin/dev --package apps/backend --package apps/web-server --package scripts`.
   - Traps: mypy --strict ratchet; frontmatter must be stripped before
     parsing; numbered steps can wrap onto indented continuation lines.

3. **PFactory: route, dedupe, emit guards, contract fields.** Same PR as
   step 2.
   - **Route:** `apps/web-server/server/mcp_stdio/router.py` gets
     `POST /plan/sessions/ingest-approved`, with the `_PlanWrite`
     dependency used by `ingest-text`. The body model is `extra=forbid`
     with the field bounds above.
   - **Service:** `apps/backend/plan/service.py` gets
     `PlanService.ingest_approved(...)`:
     - blob check;
     - authorization reused from `routes/plan_pipeline.py` (`_ingest_org`,
       `require_repo_project_role`);
     - the dedupe claim, via `acquire_emit_lease` style claim rows with a
       dedupe-specific key;
     - the non-authoring stages of `process()` (`:1167-1210`), extracting
       a helper rather than duplicating it.
   - **Session field:** `PlanSession.source_artifacts: list[dict] | None`.
   - **Edit routes:** edit, `suggestions/apply` and `process` return 409
     on artifact sessions.
   - **Emit guards:** `_emit_contract` (`:2985-3070`) gets the
     artifact-session rules.
   - **`emit_contract` in `plan/emit/contract_emit.py`:**
     - takes an `allow_fallback: bool` parameter;
     - the fallback branch (`:435`) requires `allow_fallback and env
       opt-in`;
     - `assemble_contract` adds the two provenance fields.
   - **Approval:** `approver_display` is resolved from the user record.
   - **Schema copy:** sync `apps/backend/plan/emit/contracts/task-contract.schema.json`
     from step 1.
   - **Also:** the scoped `ingest-text` proxy (`router.py:~598`,
     `IngestTextBody(**body)`) catches `ValidationError` and returns 422,
     not 500. This was seen live on 2026-11-23.
   - **Tests:** every PFactory item in the spec's Verification list.
     - Each lives in a new or existing test module near
       `tests/plan/test_contract_emit*.py`, `tests/mcp_stdio/`.
     - Add an offline end-to-end test that signs with a test key and
       verifies with AIFactory's verification logic copied as a fixture.
       If that is impractical, cover it in step 5.
   - Verify by: the full backend and web-server pytest suites that CI
     runs, plus the ratchet command above.
   - Traps:
     - never weaken the stage-machine guards (`service.py:3000-3002`);
     - REST `emit-contract` defaults `require_user_approval=False`, so the
       artifact rule must live in the service, not the router;
     - keep `approval.approved_by="pfactory"`;
     - the HMAC covers everything except `approval`, so do not put the new
       fields there.

4. **TFactory: scoped ingest without registration.**
   - Change:
     - `apps/web-server/server/mcp_stdio/router.py` scoped specs ingest
       (`:333-349`): add an optional `no_register: bool = False`. When
       true, an unknown or invisible project returns the same 404 body
       (`{"detail": "Project not found"}`, D6) and nothing is registered
       (`routes/specs.py` registration path `:358-374`, `:491-504`).
     - The ingest result adds `planner_reason` (`checkout_failed`,
       `scheduler_failed`, `auto_plan_disabled`) whenever
       `planner_scheduled` is false.
   - Tests: `tests/test_mcp_stdio_authz.py` style. Unknown and invisible
     projects get the identical response. A narrow `acw_` key without
     `api:full` can ingest with `pr_number` and read
     `/api/mcp-stdio/spec-tasks/...`.
   - Verify by: `apps/backend/.venv/bin/pytest apps/web-server/tests/ -m "not slow" -q`
     and the ratchet.
   - Traps: the #1597 bare-id status contract and the D6 wording added in
     #1651.

5. **AIFactory: provenance acceptance tests.**
   - Change: `apps/backend/tests/` (next to the trusted_plan tests). A
     contract with both provenance fields verifies and is stored verbatim
     in `context/task_contract.json`. Altering any provenance field makes
     the signature fail.
   - No production code change. If one turns out to be needed, stop and
     report.
   - Verify by: the trusted_plan test module plus the CI backend suite.
   - Traps: `AIFACTORY_SKIP_PYTHON_GATE` must not be used for this
     commit.

6. **Factory: `shared/factory-cli` package.**

## Rollback

- **CLI:** additive, so stop using `factory` and revert the Factory PR.
  Existing per-portal MCP entries are untouched.
- **PFactory:** the new route and session field are additive. Revert the
  PR, or redeploy the previous image through gitops. Artifact sessions
  already created stay readable, because the field is optional.
- **TFactory:** `no_register` defaults to false, so existing callers are
  unchanged. Revert the PR to roll back.
- **Schema:** the fields are optional with `additionalProperties: true`,
  so older consumers ignore them.

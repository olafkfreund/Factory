# Plan: fail-closed AWS conductor, pre-flight, template fixes (#3839)

Approved decisions (from the spec): canonical copy is
`.claude/skills/run-aws-demo/` in the hub, `~/.claude` copy synced from it.
Conductor: `set -euo pipefail`, no apply pipe, explicit checks on init,
validate, apply, outputs (non-empty https), pytest; read-only pre-flight
`aws apprunner list-services --max-items 1` before the trap is armed and
before the old workspace is removed; recognise "can't create new App Runner
services" with the owner message; EXIT trap keeps the primary status and turns
a cleanup failure into non-zero; never print GREEN unless pytest exit 0.
Template: factory-ttt-* names, default_tags factory-ephemeral=true, ECR access
role with depends_on, VPC connector + subnet groups + SGs. No compute-target
change (recommended follow-up: ECS Fargate or Lightsail containers). No real
AWS call, no apply.

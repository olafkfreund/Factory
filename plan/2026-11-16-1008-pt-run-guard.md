# Plan: anti-loop guardrail and per-run token ceiling (PFactory, TFactory)

Decisions from the spec: new `agents/run_guard.py` per repo (prefix `PFACTORY_` /
`TFACTORY_`): guardrail on unless `ACT_GUARDRAIL` is `0|false|no|off`;
`MAX_TURNS` default 1000; `RUN_TOKEN_CEILING` default 10M, 0 off. Guardrail halt is per session
(in memory, checked per streamed message with `client.interrupt()`). TFactory
ceiling reads persisted `status.json` usage before and after each session and in
the triager envelope (outcome failure). PFactory counts in
`PlanSession.record_usage`, raising `TokenCeilingExceeded`; `process()` emits the
usage snapshot, `build_completion_event` stamps `halt_reason`. Worktrees: PFactory and TFactory branches off dev.

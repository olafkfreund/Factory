**Accent selection:**
`:root[data-portal=plan|build|test|cockpit|meet] { --f-accent: var(--f-<portal>) }`,
defaulting to `--f-build`.

**Shared non-colour tokens:**
- type sizes: caption 12/16, body 14/20, data 13/18, body-lg 16/24,
  title 18/24, page 20/28, stat 28/32;
- `--f-font-sans`: Hanken Grotesk stack; `--f-font-mono`: JetBrains Mono
  stack;
- radius: 4 badge, 6 control, 8 card/dialog;
- spacing: a 4px grid.

`color-scheme` is light on `:root` and dark on `.dark`.

### Gates

- **`scripts/check_factory_ui_drift.py`:**
  - add `tokens.css` and `tailwind-theme.css` to the canonical set, with a
    per-file destination `src/styles/` for the React portals;
  - the unlisted-file guard globs `*.css` as well as `*.tsx`;
  - new layouts:
    - `cfactory`: `apps/frontend-web/src/styles/tokens.css`, tokens only;
    - `rfactory`: `web/public/tokens.css`, tokens only;
  - a portal may vendor a declared subset.
- **Small-text rule** in `scripts/check_banned_constructs.py`: reject
  `text-[Npx]` with N < 12, `text-[0.Nrem]` < 0.75, and CSS
  `font-size` < 0.75rem or < 12px in portal frontends. It ratchets: only
  new occurrences fail, consistent with the script's existing mode.
- **Contrast self-test** `scripts/check_token_contrast.py`, stdlib only:
  - parse `tokens.css` (hex comments, or OKLCH converted to sRGB);
  - assert ≥ 4.5:1 for every text and accent token on every surface and
    on `--f-bg`, in both modes;
  - assert `border-strong` ≥ 3:1;
  - assert `on-accent` ≥ 4.5:1 on every accent and status fill;
  - wired into the Factory CI workflow that already runs the drift check.

### Hub component

`PortalSwitcher.tsx` gains a fifth entry, Meet (RFactory), and its dots use
`var(--f-*)` tokens instead of hard-coded hexes.

## Alternatives rejected

These are listed in the #3873 plan:
- a cool grey neutral;
- APCA as the gate;
- a full shared component library first.

## Risks

- Every portal's dark mode gets one step darker. TFactory is the
  side-by-side check before the rest adopt it, with Codex's
  `#282828`/`#32302f` values as the fallback.
- A drift-gate change needs a coordinated `HUB_PIN_SHA` bump in each
  portal (C2).

## Verification

- `python scripts/check_token_contrast.py` passes, and fails on a
  deliberately weakened token in a test.
- Drift-gate tests cover CSS files and the new layouts.
- Small-text rule tests.
- The existing Factory CI passes.
